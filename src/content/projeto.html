O PROJETO

É preciso codificar para aprender

Nossa principal premissa é a de que o código fonte é um objeto de aprendizado, assim como o texto, verbal e/ou multimidia/multimodal, e, especialmente para o estudante de programação, o código tem o potencial para ser mais uma fonte de aprendizado. Dessa forma, acreditamos que a apropriação desse objeto por meio de software funcional desde o inicio do processo de aprendizagem pode ser importante para o estudante e pretendemos, desse modo, promover essa apropriação através da abordagem de softwares mais presentes no cotidiano do discente, como aplicativos para dispositivos móveis e videogames. Ademais, através da nossa prática de ensino e pesquisa, propomos que o ensino através dos tradicionais exercícios, como por exemplo, de algoritmos, P.O.O. ou arquitetura de software, comumente isolados em pequenas atividades ou estudos de casos, abram espaço para práticas com artefatos de software mais contextualizadas e conectadas às experiências previamente estabelecidas dos estudantes.
